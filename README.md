
  # ardweknow
  collection of sketches done on an atmega328p bootleg UNO board to try the parts it came with.
  
  ### for testing purposes only

Complete Pin Map
Arduino	Component
D2	Left black button
D3	Right black button
D4	Red LED
D5	Yellow LED
D6	Blue LED
D7	Green LED
D10	Red removable wire
D11	Yellow removable wire
D12	Green removable wire
D13	Blue removable wire
A1	Buzzer +
GND	Common ground
